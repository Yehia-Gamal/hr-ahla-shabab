# تقرير فحص وإصلاح 097

## الهدف
فحص عميق لنسخة 096 والتأكد من سلاسة النظام، خصوصًا الإشعارات وطلبات الموقع والرد عليها، ثم إخراج نسخة أقوى بدون كسر الملفات أو المسارات القديمة.

## أهم مشكلة فعلية تم اكتشافها
في مسار Supabase الخاص برد الموظف على طلب الموقع المباشر، كانت حالة `REJECTED_TEMPORARY` قد تُفسَّر في بعض الحالات كموافقة لأن الكود كان يعتبر أي رد ليس `REJECTED` أو `POSTPONED` موافقة ضمنية.

## الإصلاح
- أصبح إرسال الموقع يتطلب إحداثيات فعلية قبل تسجيل الموافقة.
- `REJECTED_TEMPORARY` و `TEMP_REJECT` لا تسجل كموافقة.
- التأجيل يبقى `POSTPONED`.
- الرد المؤقت يظهر للإدارة كرفض/تأجيل مؤقت وليس كموقع مرسل.
- حفظ `employee_locations` لا يحدث إلا مع إحداثيات رقمية صحيحة.
